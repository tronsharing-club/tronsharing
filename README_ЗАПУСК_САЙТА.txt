КАК ЗАПУСТИТЬ САЙТ «ТРОНШЕРИНГ» И ДОБАВИТЬ В ПОИСК ЯНДЕКСА И GOOGLE
==================================================================

1. БЕСПЛАТНАЯ ПУБЛИКАЦИЯ САЙТА ЗА 1 МИНУТУ (ЧТОБЫ ПОЛУЧИТЬ РАБОЧУЮ ССЫЛКУ):
   - Распакуй этот архив (внутри лежит готовый главный файл сайта index.html со всеми картинками и SEO-разметкой).
   - Зайди с телефона или ПК на любой бесплатный хостинг статики:
     • Netlify Drop: https://app.netlify.com/drop
     • Tiiny Host: https://tiiny.host
     • GitHub Pages: https://pages.github.com
     • Или российский хостинг (Timeweb Cloud / Яндекс Облако Object Storage / Reg.ru)
   - Загрузи папку или файл index.html — ты сразу получишь постоянную ссылку вида https://tronsharing.netlify.app.

2. КАК ДОБАВИТЬ САЙТ В ПОИСК ЯНДЕКСА И GOOGLE:
   - В файл index.html уже встроены SEO-теги (title, description, keywords, OpenGraph и микроразметка Schema.org WebApplication) и файл robots.txt.
   - Чтобы Яндекс быстрее нашёл сайт по названию «ТронШеринг», добавь свою ссылку в Яндекс.Вебмастер (https://webmaster.yandex.ru).
   - Чтобы сайт появился в поиске Google, добавь ссылку в Google Search Console (https://search.google.com/search-console).
